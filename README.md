# Playlist Maker

Playlist Maker — Android-приложение для поиска треков, предпрослушивания музыки и управления собственной медиатекой.

Проект был разработан в рамках обучения на курсе **Яндекс Практикум** и представляет собой Android-приложение для поиска треков, предпрослушивания музыки и работы с собственной медиатекой.

---

## Возможности

- поиск треков через **iTunes API**
- отображение результатов поиска
- обработка состояний экрана:
  - загрузка
  - пустой результат
  - ошибка соединения
  - ошибка сервера
- история поиска
- предпрослушивание трека
- экран медиаплеера с основной информацией о треке
- добавление трека в **избранное**
- создание плейлистов
- редактирование информации о плейлисте
- удаление плейлиста
- добавление треков в плейлист
- удаление треков из плейлиста
- просмотр деталей плейлиста
- шаринг плейлиста
- переключение **светлой и тёмной темы**
- возможность поделиться приложением
- переход в поддержку и пользовательское соглашение

## Архитектура

В проекте использовано разделение на слои:

- `data` — работа с сетью, базой данных, внутренним хранилищем и реализация репозиториев
- `domain` — модели, интерфейсы и interactor-слой
- `ui` — фрагменты, адаптеры, ViewModel и экранная логика

Для внедрения зависимостей используется **Koin**.  
Для локального хранения данных используется **Room Database**.  
Для работы с сетью используется **Retrofit**.

## Особенности реализации

### Поиск треков
Поиск выполняется через **iTunes API**.  
Для уменьшения количества лишних запросов реализован **debounce** ввода.

### История поиска
Приложение сохраняет историю просмотренных/выбранных треков и позволяет её очищать.

### Медиаплеер
Для выбранного трека доступен экран с предпрослушиванием, отображением времени воспроизведения и возможностью добавить трек в избранное.

### Избранные треки
Понравившиеся треки можно сохранять в избранное и просматривать в медиатеке отдельно.

### Плейлисты
Пользователь может:

- создавать плейлисты
- редактировать информацию о плейлисте
- добавлять треки в плейлист
- удалять треки из плейлиста
- удалять сам плейлист
- делиться содержимым плейлиста

### Темизация
В приложении реализовано переключение между светлой и тёмной темой.
